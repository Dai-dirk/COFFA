# Benchmarks
=======================

Here are the memory-intensive or irregular benchmarks that are used in the paper.

The "compile.sh" script is used to transform the loop kernel into DFG. This script requires being copied to the same folder as the target kernel, and run as "./compile.sh your_benchmark_C_code_file_name your_benchmark_name"

Although compiled DFGs are available, we recommend recompiling them yourself.
