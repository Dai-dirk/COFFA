# FGRA-BO-DSE
=======================

The BO-based automatic DSE process of FGRA is implemented by Python.

## Dependencies

### Optuna: 

Please refer to https://github.com/optuna/optuna for Optuna instalation.

### Python 3.7 or newer

## how to run

 python ./FGRA-DSE/dse-hete.py

## File catalog

**./FGRA-DSE/archSpec.py:** define the DSE flow 

**./FGRA-DSE/paraDefine.py:** define the range of design parameters that need to be explored
