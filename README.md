# LoRA ISCA Artifact Evaluation

## Overview
This repository contains the source code, benchmarks used for system-level evaluation, and related reports for the paper. Below are descriptions of each folder.

### App-Compiler
An LLVM-based front-end compiler that compiles loop kernels into DFGs. Users can follow `COFFA-Manual-1.0.pdf` in the `Resources` folder to conduct their own experiments.

### Application_Evaluation_Files
Source code for running the end-to-end accuracy evaluations (Section VIII-B-3). See `README.md` in this folder for a usage guide.

### FGRA-Compiler
A back-end compiler that maps the generated DFG to the CGRA. Users can follow `COFFA-Manual-1.0.pdf` in the `Resources` folder to conduct their own experiments.

### LoRA_SoC_Src
Source code for the LoRA SoC (only the CGRA accelerator part). Users can follow `COFFA-Manual-1.0.pdf` in the `Resources` folder to integrate the LoRA CGRA into their own Chipyard environment.

### PiecewiseChebFitter
Source code for the Chebyshev polynomial approximation algorithm. See `README.md` in this folder for a usage guide.

### SoC_Area_Report
Area reports for three SoCs generated by Synopsys DC; the results correspond to Fig. 9.

### System_level_benchmarks
Benchmarks (i.e., loop kernels) used for system-level evaluation (Section VIII-C). Users can follow `COFFA-Manual-1.0.pdf` in the `Resources` folder to compile and map these kernels to the LoRA CGRA in their own environment.

### Verilogs
Verilog files for: (1) the three SoCs used in system-level evaluation (Section VIII-C); (2) the three XCores (XCore‑A/B/C) used in unit-level evaluation (Section VIII-B).
