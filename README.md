# COFFA: A Co-Design Framework for Fused-Grained Reconfigurable Architecture towards Efficient Irregular Loop Handling

## Key Futures

COFFA is an open-source framework for a hybrid system with a RISC-V core and a fused-grained reconfigurable accelerator.
